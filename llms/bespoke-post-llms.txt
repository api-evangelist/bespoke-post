# Bespoke Post

> Bespoke Post is a New York City direct-to-consumer men's lifestyle retailer founded in 2011 by Rishi Prabhu and Steven Szaronos. It sells curated menswear, gear and home goods through a free-to-join membership: members answer an onboarding quiz, preview a personalized monthly "Box of Awesome" shipment they can swap or skip, and buy at member pricing. The company also operates its own labels — Line of Trade and Fieldworth (apparel), Halfday (travel), Wren (outdoor), Ash and Fir (home and fragrance) and Marcellin (kitchen and bar).

Bespoke Post publishes no public developer portal, no API documentation and no
machine-readable API specification (no OpenAPI, AsyncAPI, GraphQL schema, MCP
server or A2A agent card was found on any host as of 2026-08-02). It does run an
undocumented first-party storefront API under /api/ on its own domain, and it
names eight of those paths in robots.txt with explicit Allow directives for AI
agents — while disallowing /api/ to every unnamed agent.

Generated by API Evangelist from the public Bespoke Post surface. Not published
by Bespoke Post.

## API surface

No developer documentation exists for this API. The paths below are the ones
Bespoke Post names in its own robots.txt with AI-agent Allow directives. They are
read-oriented, session-scoped where noted, and sit behind Cloudflare bot
management — a client that is not an IP-verified crawler receives HTTP 403.

- `GET https://www.bespokepost.com/api/collections/`: Product collections.
- `GET https://www.bespokepost.com/api/products/`: Product catalog.
- `GET https://www.bespokepost.com/api/current_user?`: Current session/account (authenticated).
- `GET https://www.bespokepost.com/api/current_user/carts`: Cart for the current session.
- `GET https://www.bespokepost.com/api/current_user/box_assignments`: Monthly box assignment for the current member.
- `GET https://www.bespokepost.com/api/current_user/for_you_assignments`: Personalized recommendation assignments.
- `GET https://www.bespokepost.com/api/user_segments/`: Audience/segment metadata.
- `GET https://www.bespokepost.com/api/questions/`: Onboarding quiz questions.

Agents explicitly allowed on those paths: Googlebot, Googlebot-Image, Bingbot,
GPTBot, ChatGPT-User, OAI-Searchbot, ClaudeBot, anthropic-ai, PerplexityBot,
meta-externalagent, cohere-ai. All other agents are disallowed from /api/.
